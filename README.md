# Student Management System Using MongoDB

## Introduction
This project is a Student Management System developed using MongoDB.

## Features
- Create database and collection
- Insert student records
- Display student records
- Update student records
- Delete student records
- Search students
- Sort student records
- Count documents
- Use comparison operators
- Use AND and OR operations

## Technologies Used
- MongoDB
- NoSQL

## Project Description
The project manages student information such as roll number, name, age, marks, and city using MongoDB queries.

## Operations
- CRUD Operations
- Comparison Operators
- Sorting
- Filtering
- AND / OR operations
